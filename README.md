## Stack

- Laravel 13
- PHP 8.4
- MySQL/MariaDB
- Blade, CSS, JavaScript

## Status

Tahap 0.1: project setup selesai. Fitur aplikasi belum ditambahkan.

## Menjalankan

1. `composer install`
2. Salin `.env.example` menjadi `.env`
3. Atur koneksi database di `.env`
4. `php artisan key:generate`
5. `php artisan migrate`
6. `php artisan serve`

Buka `http://127.0.0.1:8000`.

## Catatan

Project ini tidak memakai Vite, Tailwind, atau framework CSS. Tampilan memakai Blade, CSS biasa, dan JavaScript vanilla.
